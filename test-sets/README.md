# Test sets

Put real drawing sets here for local testing. Everything in this folder except this README is git-ignored, because sets can contain client data.

Keep one **seeded error set** here: a copy of a clean set with known deliberate mistakes (wrong sheet number, missing note, broken callout, misspelling, missing north point). Every check must catch its seeded error, and an audit run on this set is the acceptance test for each phase.
