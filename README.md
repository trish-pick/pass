# PASS

**Pre-issue Audit & Sheet Scan.** Nothing leaves the office until it PASSes.

PASS audits architectural drawing sets (PDF) against a practice's own requirements before they issue, and produces a correction list for the drafter.

> PASS checks your drawings against your own practice requirements. It does not assess compliance with the NCC or Australian Standards.

The full build brief is in [`CLAUDE.md`](./CLAUDE.md). Setup steps are in [`docs/SETUP.md`](./docs/SETUP.md).
